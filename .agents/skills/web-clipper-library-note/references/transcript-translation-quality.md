# 逐字稿翻译与终审标准

目标是忠实、自然、完整、连贯、保留风格、可查证且不越权。

## 优先级

1. 原意和事实准确。
2. 论证与限定完整。
3. 作者风格和语气。
4. 中文自然与阅读节奏。
5. 表面字词对应。

## 翻译前

识别说话人、主题、风格、专有名词、核心术语、疑似 ASR 错误和多义句。没有证据时不猜。

## 忠实与自然

允许调整语序、拆分长句、合并字幕碎片和补足中文语法所需连接。禁止删除关键条件、添加背景或建议、修正作者立场、把推测变成事实。

重点保留：

- 可能性与不确定性。
- 范围与频率。
- 否定、条件、转折和比较对象。
- 主观来源、强调、反问和讽刺。
- 说话人的节奏、重复和自我修正。

## 术语与 ASR

使用稳定译法；没有稳定译法时首次写“中文（English）”。无法确认时保留原词并标记 `〔待确认〕`。英文证据保持原样，疑似 ASR 错误写入质量说明。

## 语义分组

- 在完整句、问答、例子或小论证结束处切分。
- 使用该组第一条英文证据时间戳。
- 每条英文证据出现且只出现一次。
- 中文块不能加入没有英文依据的承接句。

## 对照终审

检查漏译、误译、反译、增译、限定词、因果、指代、数字、专名、术语一致性、翻译腔、风格和证据覆盖。只修明确错误，不为个人措辞偏好无故重写。

元数据必须准确说明中文由 Codex 生成还是由用户提供。运行环境无法确认模型时，不宣称使用特定模型。
