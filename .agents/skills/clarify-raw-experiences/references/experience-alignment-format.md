# Experience 理解对齐格式

目标是还原“当时发生了什么、为什么这样做、结果如何、现在怎样理解”，不是把经历加工成文章。

## 事件复盘

```markdown
### 我对这份 Experience 的理解

**情境与目标**

- 情境：
- 当时最想获得：

**事件与行动链**

1. 发生了什么。
2. 当时如何判断。
3. 采取了什么行动。
4. 环境给出什么可观察反馈。

**结果**

- 即时结果：
- 延迟结果：

**事后解释与替代解释**

- 用户当前的解释：
- 其他可能解释：
- 仍不能确认：

**可复用信号**

- 情境：
- 观察信号：
- 当前动作：
- 失效边界：
```

## 判断形成

记录触发情境、原有状态、需要作出的判断、选项与约束、形成的判断、执行动作、后续结果和仍待验证内容。

## 追加

首次确认后使用 `## 理解对齐版`。已有对齐版时使用：

```markdown
## 后续验证与状态更新

### YYYY-MM-DD

- 新事实：
- 对原判断的支持、补充、修正或挑战：
- 当前知识出口：
```

历史记录保留，不用新理解覆盖旧认识。
