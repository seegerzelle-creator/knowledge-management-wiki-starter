# Capture 理解对齐格式

目标是降低未来重新进入思考的成本，不是把碎片加工成文章。

## 轻量版

适用于单个短问题、观察或灵感：

```markdown
### 我对这条 Capture 的理解

**我理解的核心**

...

**下一步思考入口**

...
```

## 标准版

适用于问题链、复杂张力、语音转写和松散对话：

```markdown
### 我对这条 Capture 的理解

**核心问题**

...

**当前思考链**

1. ...

**核心张力**

...

**尚未明确的条件**

- ...

**下一步思考入口**

...
```

没有内容的小节省略，不为模板完整填空话。

## 确认后追加

```markdown
## 理解对齐版

> Codex 基于用户于 YYYY-MM-DD 的确认整理。本节用于未来回顾，不替代上方原始捕捉。

### 核心问题

...
```

已有对齐版时，不覆盖旧版本；追加带日期的理解更新。

## 理解纪律

- 明确写出的内容可以复述。
- 推断使用“我的理解是”“可能”等措辞。
- 不补写未知动机、情绪、经历或结论。
- 不把问题改成答案，不删除尚未解决的矛盾。
- 澄清问题最多 3 个。


## 使用前提

先完成逐篇背景确认；预览先写明用户确认的原始情境和对象。背景不明不得使用模板推断，出口搜索在背景和理解确认后进行。
