# Query Feedback

## 继续读取

- 需要保存个人原始信号时读取 `Rules/raw-rules.md`。
- 需要创建 Wiki 页面时读取 `Rules/ingest-workflow.md`。
- 涉及旧判断时读取 `Rules/knowledge-maintenance.md`。
- 读取失败时停止写入。

## 何时调用知识库

当问题明显涉及用户的经验、项目、偏好、历史判断、长期方向或可复用方法时，主动搜索相关 Wiki；普通事实问题不必强制检查。

## 帮助用户思考

判断、策略、创作和复盘任务中：

- 先给当前最合理的判断。
- 区分已知事实、解释和假设。
- 指出 2-3 个可观察实践信号。
- 说明核心取舍和失效条件。
- 给出一个具体下一步。

AI 建议不能直接包装成用户已确认的个人结论。

## 对话沉淀

用户说“记录一下”“这个以后要用”等时：

1. 提炼最小必要信号。
2. 说明建议保存为 Capture、Experience、Output 或 Wiki 候选。
3. 默认不保存完整对话。
4. 需要写入时先按对应规则确认范围。

用户说“先别记录”时，不创建或修改文件。

## 实践信号

适合复用时使用：

```text
- 情境：
- 当时判断：
- 实际结果：
- 可复用信号：
- 下次观察：
```


## 授权、归属与最小记录

复用本轮已明确的目标和写入范围，不对普通已授权操作重复询问；Capture 背景、敏感资料、正式 Synthesis 和重大版本等独立关口保留。
未筛选 AI 回答不能成为用户个人事实；历史个人结论先核对归属、时间、用途、冲突和证据强度。
明确要求执行、翻译或格式整理时直接完成，不强加思考训练。只读讨论不自动写日志或候选档案。
商业资料优先留在对应工作区；仅把经批准的匿名化、可迁移经验带入个人库。
